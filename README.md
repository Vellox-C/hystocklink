# HyStockLink

A Fabric mod that lets you switch Minecraft accounts from the title screen without restarting the game.

A draggable widget appears on the title screen. Paste your account token into it, click Activate, and your session is swapped instantly. No launcher restart needed.

**Tokens are available at [hystock.shop](https://hystock.shop).**

## Supported versions

| Minecraft | Loader | Status |
|-----------|--------|--------|
| 1.21.9    | Fabric | Supported |
| 1.21.10   | Fabric | Supported |
| 1.21.11   | Fabric | Supported |
| 26.1      | Fabric | Supported |

The 26.1 JAR covers 26.1, 26.1.1, and 26.1.2.

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/installer/) for your MC version.
2. Download the correct JAR for your version from the [releases page](https://github.com/Vellox-C/hystocklink/releases).
3. Drop it into your `mods/` folder.
4. Launch the game. The HyStockLink widget will appear on the title screen.

## Usage

1. Open the widget on the title screen and click **Activate Account**.
2. Paste your token and confirm.
3. Your session is now switched. Connect to any server as that account.

Hold **Left Ctrl** and drag the widget to reposition it. Position saves automatically.
